# 模型导入编辑与原库属性

## 使用入口

编辑页：http://localhost:8080/editor.html 。展示页：http://localhost:8080/gallery.html ，选择“我的模型”。

1. 选择或拖入一个 GLB / FBX 主模型。若引用外部图片，同时选择所有配套图片。
2. 调整名称、位号、类型、位置、角度、三轴缩放、投影/受影和入口/出口位置。
3. 查看节点列表、网格/三角形/材质/动画统计，选择动画预览。尺寸沿用加载器解析后的场景单位，需要按源文件情况手动换算缩放。
4. 保存到模型库，在同一浏览器、同一来源地址（包括端口）下持久化模型原文件、配套资源和配置。刷新展示页后出现格子，也可以回编辑页点击模型库条目继续修改。
5. 导出配置 JSON 可记录元数据和变换，但不含模型二进制；请保留原模型与贴图。本页不会把文件写入服务器目录，也不会自动绑定到 plant.js 或真实 PLC。

资源按文件名匹配，遇到不同目录下同名图片需要先消除重名。Draco/Meshopt 压缩 GLB 目前未接解码器，需先输出未压缩 GLB。FBX 兼容性以 Three.js FBXLoader 支持范围为准。本次验证覆盖基础 ASCII FBX，不代表已验证所有 FBX 导出器、骨骼或材质特性。

## 原代码的属性并非统一表单

原模型工厂返回 Three.js Group / Mesh，其构造参数、三维属性、自定义数据和设备业务数据分散存放。

| 层次 | 位置 | 已有内容 |
|---|---|---|
| 几何构造参数 | js/factory.js | 每个函数单独定义，见下表 |
| 对象变换 | Group / Mesh | position、rotation（弧度）、scale、visible、children、name、userData |
| 网格/材质 | Mesh.geometry / Mesh.material | 几何、纹理、color、metalness、roughness、opacity、transparent、castShadow、receiveShadow；具体材质可支持的字段不同 |
| 场景交互登记 | js/plant.js | 示例的 sel(group,title,rows,ids,o)，形成可选设备记录；labels 与 pumps 也在场景层组织 |
| 设备台账 | js/sim.js 的 DEV | 泵有 id、kind、tag、name、vfd、spec、lock；仪表还有 unit 等，按设备种类定义 |
| 运行状态 | js/sim.js 的 D | run、fault、auto、rt。S 保存工艺液位、流量、pH、报警等场景数据 |

### 模型工厂原有参数

| 函数 | 参数 |
|---|---|
| pump | {scale=1, color=M.pump}。这里 color 实际接收材质对象，并非颜色字符串 |
| mixer | {shaft=3, color=M.pump}。color 同样为材质对象 |
| rectTank | w,d,h,{water,dividers,rail,wall,waterInset,waters} |
| clarifier | r,h,{water,bridge} |
| vTank | r,h,{top,bottom,legs,mat,bands,rail,ladderSide,open,water} |
| platform | w,d,h=0.35,cell=2 |
| railing | pts,y,{h,mat,step,closed} |
| ringRailing | r,y,{h,mat,posts} |
| ladder | h,mat=M.rail |
| pipe | pts,{kind,r,flow,speed,bend,dash,seg} |
| valve | axis='x' |
| scrubber | h=9,r=1.5 |
| arrowHead | kind='water',r=0.5 |
| blowerCabinet / boiler / flameArrester / boosterSkid / centrifugalFan | 原函数无对外参数，内部尺寸固定；返回后仍可修改对象变换 |
| waterMaterial | {deep,light,foam,bubbles,round,size,speed} |
| box / cyl | 基础尺寸、材质、分段等，用于拼装设备 |

### 自定义 userData

- 管道：pipe、curve、len、r、kind、pts；有流动效果时另有 flow 句柄。示例场景还添加 actId 绑定设备运行。
- 搅拌机/刮泥桥动态部件：dynamic=true，anim={name,speed}，并加入 animated 更新列表。
- nozzles 是参考文档建议的接口约定，原有模型并未统一提供。这个编辑页新增 inlet/outlet 局部坐标，挂在导入包装对象 userData.nozzles；它们随外层变换，但不自动生成管道。

### 示例

```js
const model = F.pump({ scale: 1.2, color: F.M.pump });
model.position.set(3, 0, 5);
model.rotation.y = Math.PI / 2;
// 设备位号、启停/故障和报警仍由外部台账与业务逻辑关联。
```
