# 模型工厂与渲染实验室

打开 http://localhost:8080/gallery.html 。本页新增于示例目录，复用仓库的 factory.js 与 fx.js，未修改原仓库。

共 34 个样本：14 个设备模型及配置变体、10 个基础部件与材质/文字样本、10 个水面与特效样本。格子独立旋转缩放，按包围盒适配，跨格比例不代表真实尺寸。

左侧公共设置同时影响所有样本：环境光、主光强度/颜色/方位/高度、环境反射、曝光、色调映射、投影与柔和度、AO、辉光、特效、动画速度、自动旋转、线框。日间、夜间辉光、侧光阴影预设可快速对比。放大后仍可使用左侧设置。

渲染采用单一 WebGL 上下文和可见格子裁剪；AO、辉光、色调映射使用 Three.js 后处理。粒子显示比例已按小格尺寸适配。此页为查看工具，不包含场景组态编辑器或真实设备接入。

服务重启：在此示例目录运行 `python serve.py 8080`。校验：`node doc/check-gallery.cjs`，结果见 gallery-verification.json，截图在 exports。
